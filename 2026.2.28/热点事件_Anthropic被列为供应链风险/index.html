    Anthropic供应链风险

    标题：Anthropic被美政府列为供应链风险，openai迅速倒戈？

    前段时间吃瓜看到 Anthropic 跟美国军方闹矛盾了，A社不同意后者无限制地把AI技术用于针对美国公民的大规模监视，以及开发全自动武器系统的计划。

    刚刚 Anthropic 发了个声明，意思是跟美国政府谈判僵住了，国防部长直接在X上宣布，不谈了，从今天起 Anthropic 正式被列为国家安全供应链风险公司（美国公司首次），他们没提前收到通知。

    国防部长也是一点情面不留，火药味极浓，直接艾特 Anthropic 老大达里奥，说他虚伪、伪善，爱作秀，披着道德外衣只看重利益，实则一点不爱国。 ![[Pasted image 20260228143311.png]]

    人身攻击倒是没什么（估计达里奥也听惯了），但是“供应链风险”的标签对 Anthropic 的影响还是极大的，而且会是长期性的。想当年华为、海康威视也是一样的遭遇。

    对于Anthropic这样的美国AI公司，供应链风险意味着什么？

    丢掉现在跟美国军方的合同事小，合同约2亿美元，Anthropic年收入140亿美元，占比不到1.5%。

    更大的威胁是"连坐效应"，只要是跟军方有合作，或者想合作的公司，你的供应链里都不能出现Anthropic。不过这里面也涉及到“供应链风险”执行是否严格的问题，美国政府非要把Anthropic逼到绝境，可能会要求所有与五角大楼有业务的公司切断和Anthropic的关系。要知道美国八大科技公司，几乎都有军工业务，Anthropic 现在又高度依赖 AWS 和 Google Cloud 分发。

    Anthropic的tob 企业级业务，可能也会遭遇合规恐慌，一些跨国银行、医药巨头或能源公司是不是会迫于政策连带风险，停止跟Anthropic的合作尚不得而知。

    不过B端最直接、致命的影响还是政府和国防这块市场，这会是AI未来最大的B端市场之一。Anthropic原本是第一家进入美国军方机密网络的AI公司，这个先发优势现在被清零了。

    竞争对手势必会迅速跟进，事实上就在国防部长那条X发布后几小时后，OpenAI表示已与五角大楼达成协议，将向其机密系统提供AI技术。

    讽刺的是，奥特曼前几天还在上CNBC节目时表示“总体上信任Anthropic，认为他们很重视安全，五角大楼不应以《国防生产法》威胁这些公司”。看似是站在Anthropic一边，实则私底下已经在秘密谈判了，这政治手腕玩得是真溜，也可见军方的合作对于如今的AI公司有多重要。

    BTW，奥特曼的声明也很有意思，AI届的政治家当仁不让。

    ![[Pasted image 20260228154931.png]]

    先声明我们也有两项安全原则（跟Anthropic一样，但是坚持不坚持我们说了算）——禁止国内大规模监控，人类对包括自主武器系统在内的武力使用负有责任。

    但是不只说自己，还要带上美国军方，表示政府也认同这个原则，既给对方台阶下，也为后续“提要求”做了铺垫，比如我们要派技术人员去帮忙解决问题，为了确保其安全性，我们将仅在云网络上部署，这意味着OpenAI 保留了物理上的“断网权”，也算是留了一点筹码在手上。

    不过你要说真是因为奥特曼情商高，才能这么快搞定五角大楼，我觉得也未必。相比喜欢制造麻烦的达里奥，能屈能伸、跟川普关系更好的奥特曼显然是长期合作一个更好的选择。

    虽然跟政府谈崩了，但这事对于Anthropic也不是没有一点好处。Anthropic坚持安全原则的立场反而是一种品牌背书，尤其在硅谷、学术界、欧洲市场、以及关注AI安全的企业客户眼中。

    X上大批用户也表示了对Anthropic的支持，“关于安全原则那段话值得裱到卢浮宫去”，“卸载了ChatGPT，开始投入Claude Max（真有钱啊你）”。

    ![[Pasted image 20260228160125.png]]

    而在奥特曼的声明下，更多人表示不理解，“你的立场和 Anthropic 完全一样吗？如果完全一样，为什么你们拿到了合同，而他们却受到了惩罚？”，当然也有人直接点出了其中的猫腻。

    ![[Pasted image 20260228155829.png]] 但AI毕竟不是一盘完全toc的生意，尤其对一家正在高速发展，有可能成为万亿级巨头的公司来说。

    所以 Anthropic 也没有坐以待毙，声称将就五角大楼的决策提起诉讼。但现实是，在美国法院跟行政机关，尤其还是军方打官司的代价是极高的。赢得几率很小，即便赢了，也会输掉整个政府市场的关系。官司打两三年，期间政策不确定性持续悬在头上，对企业采购决策的影响会一直存在。

    不过倒也有回旋的余地，那就是Anthropic 争取跟五角大楼重新坐到谈判桌上，达成一份协议。

    国防部长声明里提到的那句“Anthropic将继续提供服务，期限不超过六个月，以便我们顺利过渡到更优质、更符合爱国精神的服务。” 意思就是，你们只有六个月时间，否则免谈。

    但如果谈不成，除非Anthropic在技术上远远甩开竞争对手（很难），否则它在这场全球AI竞争中获胜的概率，也会大大降低。
